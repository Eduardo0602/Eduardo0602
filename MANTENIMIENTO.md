# Cómo mantener este perfil

Este repo (`Eduardo0602/Eduardo0602`) es el README que GitHub muestra en tu perfil.

| Quiero… | Dónde |
|---|---|
| Añadir un proyecto | `README.md`, entre `<!-- PROJECTS:START -->` y `<!-- PROJECTS:END -->`: copiar un bloque `<td>…</td>` (título con enlace, pregunta en cursiva, un resultado verificable, 2–3 etiquetas `<code>`). Cada `<tr>` lleva dos proyectos; mantener los 4 más fuertes arriba |
| Añadir una habilidad | Entre `<!-- SKILLS:START -->` y `<!-- SKILLS:END -->`, en la fila que corresponda. Color: `7A1F2B` lenguajes, `4A0F17` estadística/ML, `9C3341` datos, `555555` flujo de trabajo. Logos: https://simpleicons.org |
| Cambiar el banner | `assets/banner.svg` (texto, colores). Fuentes del sistema solamente: GitHub no carga fuentes web en SVG |
| Cambiar disponibilidad o lo que estás haciendo | Insignia "Open to" en la cabecera y bloque `<!-- NOW:START -->` (revisar cada mes) |

Reglas: sin raya larga (usar · o coma); cifras solo si están en el README del proyecto o en `cv-maestro/references/hechos_canonicos.md`; nada de ARCH más allá de rol, métodos y tamaño de entregables (acuerdo de confidencialidad); no publicar teléfono.

O simplemente pide a Claude: "añade el proyecto X a mi perfil de GitHub".
